# Deployment & Releases User Stories

## US-1 Update Environment

As an operator,

I want to update an existing environment to a newer application version,

So that I can deploy a new release without recreating the environment.

---

## US-2 Monitor Rollout

As an operator,

I want to monitor the rollout progress,

So that I know whether the deployment completed successfully or failed.

---

## US-3 Deployment History

As an operator,

I want to view the deployment history of an environment,

So that I can track previous versions and deployment results.
