# Observability Definition of Done

O sarcină de observability este considerată finalizată atunci când:

- configurația poate fi pornită și testată local;
- aplicația expune metricile necesare;
- Prometheus poate colecta metricile;
- dashboardurile afișează date valide;
- alertele au reguli și praguri documentate;
- configurația nu conține parole, tokenuri sau alte secrete;
- fișierele YAML și JSON sunt valide;
- modificările nu strică funcționalitățile existente;
- există instrucțiuni de rulare și verificare;
- modificările au fost verificate printr-un test manual sau automat;
- codul și configurațiile au fost revizuite înainte de integrare.
